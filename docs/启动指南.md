# 项目启动指南

本项目使用 Docker 启动。第一次运行只需要完成下面 4 步。

## 1. 打开 Docker Desktop

确认 Docker Desktop 已启动，然后打开 CMD（命令提示符）：

```bat
REM 进入 D 盘的项目目录
cd /d D:\project\aiknowledge

REM 确认 Docker 可用
docker --version
```

## 2. 创建配置文件

```bat
REM 复制一份本地配置
copy .env.example .env

REM 使用记事本打开配置文件
notepad .env
```

在 `.env` 中找到并修改下面 4 项：

```dotenv
# 数据库密码
POSTGRES_PASSWORD=123456

# 这里的密码必须和 POSTGRES_PASSWORD 一样
DATABASE_URL=postgresql+asyncpg://aiknowledge:123456@postgres:5432/aiknowledge_v2

# 管理后台登录密码
ADMIN_PASSWORD=123456

# 随便填写一个长度超过 32 位的字符串
SESSION_SECRET=12345678901234567890123456789012
```

其他配置暂时不要修改。

## 3. 启动后端

```bat
REM 启动数据库、Redis、后端 API 和文档处理任务
docker compose up -d --build postgres redis api worker
```

第一次启动需要下载和构建镜像，等待时间可能较长。

查看是否启动成功：

```bat
REM 查看后端服务状态
docker compose ps
```

看到以下结果说明后端已启动：

- `postgres`：`healthy`
- `redis`：`healthy`
- `api`：`healthy`
- `worker`：`running`

后端地址：

- API 文档：<http://localhost:8000/docs>
- 后端健康检查：<http://localhost:8000/health>

## 4. 启动前端

后端正常后执行：

```bat
REM 启动管理控制台
docker compose up -d --build console
```

浏览器打开：<http://localhost:5173>

登录账号：

```text
邮箱：admin@example.local
密码：你在 .env 中设置的 ADMIN_PASSWORD
```

## 常用命令

```bat
REM 查看所有服务状态
docker compose ps

REM 查看后端报错日志，按 Ctrl+C 退出日志查看
docker compose logs -f api

REM 查看文档处理任务日志
docker compose logs -f worker

REM 重启整个项目
docker compose restart

REM 停止整个项目，数据库数据会保留
docker compose down
```

> 不要执行 `docker compose down -v`，它会删除数据库数据。

## 启动失败怎么办

先执行：

```bat
REM 查看后端最近 100 行日志
docker compose logs --tail=100 api
```

最常见的问题是 `.env` 中这两个密码不一致：

```dotenv
POSTGRES_PASSWORD=123456
DATABASE_URL=postgresql+asyncpg://aiknowledge:123456@postgres:5432/aiknowledge_v2
```

修改 `.env` 后重新启动：

```bat
REM 重新创建服务，让新配置生效
docker compose up -d --build --force-recreate
```
