# 项目启动指南

本项目使用 Docker 启动。第一次运行只需要完成下面 4 步。

## 1. 打开 Docker Desktop

确认 Docker Desktop 已启动，然后打开 CMD（命令提示符）：

```bat
REM 进入 D 盘的项目目录
cd /d D:\project\aiknowledge

REM 确认 Docker 可用
docker --version
```

如果提示 `docker 不是内部或外部命令`，说明 docker CLI 不在 PATH 中，请改用全路径（后续所有 `docker` 命令同样替换）：

```bat
"C:\Users\刘少华\AppData\Local\Programs\DockerDesktop\resources\bin\docker.exe" --version
```

## 2. 创建配置文件

```bat
REM 复制一份本地配置
copy .env.example .env

REM 使用记事本打开配置文件
notepad .env
```

在 `.env` 中找到并修改下面 4 项：

```dotenv
# 数据库密码
POSTGRES_PASSWORD=123456

# 这里的密码必须和 POSTGRES_PASSWORD 一样
DATABASE_URL=postgresql+asyncpg://aiknowledge:123456@postgres:5432/aiknowledge_v2

# 管理后台登录密码
ADMIN_PASSWORD=123456

# 随便填写一个长度超过 32 位的字符串
SESSION_SECRET=12345678901234567890123456789012
```

其他配置暂时不要修改。`.env` 按分区组织（数据库、队列与缓存、平台基础、管理员会话、模型兜底配置、模型密钥注册区、运行面限额、远程抓取）；后续要使用模型配置中心时，在"模型密钥注册区"填写对应密钥（如 `MODEL_KEY_ALIYUN_CHAT`、`MODEL_KEY_ALIYUN_EMBEDDING`），模型管理页的条目会按变量名引用它们，密钥不会写入数据库。

另外本地运行推理类模型时，建议把 `ANSWER_TIMEOUT_SECONDS` 调为 30（默认 15 秒对推理模型不够）。

## 3. 启动全部服务

```bat
REM 启动数据库、Redis、API、入库 Worker、定时调度器和管理控制台
docker compose up -d --build api worker scheduler console
```

第一次启动需要下载和构建镜像，等待时间可能较长。

查看是否启动成功：

```bat
REM 查看后端服务状态
docker compose ps
```

看到以下结果说明全部服务已启动：

- `postgres`：`healthy`
- `redis`：`healthy`
- `api`：`healthy`
- `worker`：`running`
- `scheduler`：`running`
- `console`：`running`

后端地址：

- API 文档：<http://localhost:8000/docs>
- 后端健康检查：<http://localhost:8000/health>

> 注意：本机 8000 端口目前被其他项目占用，API 不经 8000 直接访问；日常开发通过前端的 5173 同源代理调用后端，不影响功能验证。

启动后的只读验收：

```powershell
# 检查容器状态、健康/就绪、容器内迁移版本、最新 OpenAPI 和控制台首页
powershell -ExecutionPolicy Bypass -File .\scripts\verify-runtime.ps1
```

脚本不会重建服务、删除数据库或删除任何数据卷。若只修改前端代码，也可以进入下面的本地开发模式：

## 4. 本地开发前端（可选）

本地 pnpm dev 提供 HMR 热更新，改动立即生效。在另一个 CMD 窗口执行：

```bat
REM 进入独立前端目录
cd /d D:\project\aiknowledge\frontend

REM 第一次运行时安装依赖
pnpm install

REM 启动前端开发服务，/control、/runtime 等请求会代理到容器内的后端
pnpm dev
```

浏览器打开：<http://localhost:5173>

Docker Console 与 pnpm dev 二选一，不要同时占用 5173：

```bat
REM 启动管理控制台
docker compose up -d --build console
```

登录账号：

```text
邮箱：admin@example.local
密码：你在 .env 中设置的 ADMIN_PASSWORD
```

## 常用命令

```bat
REM 查看所有服务状态
docker compose ps

REM 查看后端报错日志，按 Ctrl+C 退出日志查看
docker compose logs -f api

REM 查看文档处理任务日志
docker compose logs -f worker

REM 重启整个项目
docker compose restart

REM 停止整个项目，数据库数据会保留
docker compose down
```

> 不要执行 `docker compose down -v`，它会删除数据库数据。

## 启动失败怎么办

先执行：

```bat
REM 查看后端最近 100 行日志
docker compose logs --tail=100 api
```

最常见的问题是 `.env` 中这两个密码不一致：

```dotenv
POSTGRES_PASSWORD=123456
DATABASE_URL=postgresql+asyncpg://aiknowledge:123456@postgres:5432/aiknowledge_v2
```

修改 `.env` 后重新启动：

```bat
REM 重新创建服务，让新配置生效
docker compose up -d --build --force-recreate
```
