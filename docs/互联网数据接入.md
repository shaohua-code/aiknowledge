# 互联网数据接入说明

本功能用于把公开网页、公开 API、资讯订阅和结构化文件持续接入知识库。创建数据源后，抓取、解析、切片和向量化由后台任务完成，页面不用等待网站响应。

## 支持范围

| 数据来源 | 支持内容 | 使用建议 |
| --- | --- | --- |
| 网页 | HTML 正文、标题、常见中文编码 | 优先填写文章详情页；依赖登录或纯 JavaScript 渲染的页面应改用公开 API 或 RSS |
| API | JSON、JSON Lines（NDJSON） | 支持 GET、POST、查询参数和 JSON 请求体；可用 `data.items`、`$.data.items`、`results[0]` 提取指定节点 |
| 订阅源 | RSS、Atom、通用 XML | 适合新闻、公告和定期更新的数据 |
| 表格数据 | CSV、TSV | 第一行应为字段名，系统会把每一行转换成可检索文本 |
| 普通文本 | TXT、Markdown | 支持 UTF-8、UTF-16、GB18030、Big5 等常见编码 |

单次最多抓取 20 MB，默认超时 20 秒，遇到网络超时、限流或临时服务器错误会自动重试 2 次。最多允许 5 次安全重定向。

## 推荐操作

1. 进入知识库，点击“接入互联网数据”。
2. 优先选择“自动识别”，填写公开网址。
3. API 有多层 JSON 时，再填写 JSON 路径；普通网页不需要填写。
4. 点击“测试连接并预览”，确认状态码、内容大小和预览内容。
5. 确认后创建数据源，在“入库任务”中查看抓取、解析、切片和发布进度。
6. 原网址内容更新后，点击文档旁的“重新抓取”生成新版本。新版本成功前，旧版本继续可用。

## 兼容与降级方案

- 网站返回 HTML，但按 API 接入：改为“自动识别”或“网页”；如果地址本应返回 JSON，请检查 API 地址是否写错。
- 页面依赖 JavaScript 才显示内容：优先使用网站公开 API、RSS、导出 CSV，或把渲染后的正文保存为文件上传。本版本不执行第三方页面脚本。
- 页面需要登录、Cookie、Token 或 API Key：当前公共数据源不会保存或发送登录凭证。建议由业务后端定时导出无敏感信息的数据，再通过后续受控入库接口接入。
- 网站限流或偶发 5xx：系统会自动退避重试；持续失败时请降低抓取频率，或联系数据提供方申请稳定接口。
- 中文乱码：系统会依次识别响应头、HTML 编码声明、UTF-8、GB18030 和 Big5；仍乱码时建议使用 UTF-8 导出文件。
- JSON 结构变化：未填写 JSON 路径时会保留完整 JSON；填写路径后若节点消失，任务会明确提示路径不存在，避免悄悄导入空数据。
- 文件太大：按时间或主题拆成多个小文件，或者在上游 API 增加分页。单次内容上限可通过后端环境变量调整。

## 安全限制

系统只访问公开的 HTTP/HTTPS 地址。内网、localhost、回环、保留地址、URL 中的账号密码、敏感请求头和疑似密码或 Token 的查询参数都会被拒绝。每次重定向都会重新检查目标，HTTPS 地址不能降级跳转到 HTTP。

## 常见错误

| 错误码 | 含义 | 处理方式 |
| --- | --- | --- |
| `REMOTE_URL_INVALID` | 地址不是完整的 HTTP/HTTPS 地址 | 补全 `https://` 和完整路径 |
| `REMOTE_PRIVATE_ADDRESS_BLOCKED` | 地址解析到内网或保留 IP | 改用可公开访问的地址 |
| `REMOTE_DNS_FAILED` | 域名无法解析 | 检查域名、网络或 DNS 配置 |
| `REMOTE_ACCESS_DENIED` | 对方返回 401 或 403 | 使用无需登录的公开地址 |
| `REMOTE_RATE_LIMITED` | 对方限制访问频率 | 稍后重试或降低抓取频率 |
| `REMOTE_TIMEOUT` | 连接或读取超时 | 检查对方服务，或拆分数据 |
| `REMOTE_CONTENT_TOO_LARGE` | 内容超过大小上限 | 分页、拆分文件或调整服务配置 |
| `REMOTE_API_NOT_JSON` | API 地址实际没有返回 JSON | 检查地址，或改为自动识别 |
| `REMOTE_JSON_PATH_NOT_FOUND` | 指定 JSON 节点不存在 | 用连接预览核对实际 JSON 结构 |
| `REMOTE_JS_RENDER_REQUIRED` | 页面正文依赖浏览器脚本生成 | 改用 API、RSS 或导出文件 |
| `REMOTE_CONTENT_TYPE_UNSUPPORTED` | 内容格式暂不支持 | 转换为 HTML、JSON、XML、CSV 或文本 |

页面会同时展示错误原因、处理建议、失败阶段和请求 ID。需要排查后台日志时，使用请求 ID 可以快速定位同一次任务。
