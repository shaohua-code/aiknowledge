# AI 知识中台维护入口

从当前目录定位 aiknowledge 仓库，读取 `docs/项目重写执行书.md`。

- 第 0 节：单文件目录、执行指令与范围。
- 第 21 节：完整 `--更新` 工作流及触发规则。
- 第 22–24 节：代码审计与前后端架构。
- 第 25–26 节：实施状态、精确续接点与追加式修改记录。
- 第 27 节：所有第一方代码必须编写中文注释的强制规则。

按本轮用户实际范围实施与核对，所有上述文档内容写回同一个执行书；不要再创建单独的架构、审计、状态或修改记录文件。已有 README/API 说明仅在直接受影响时同步。

单独 `--更新` 只审计与同步，不自动重写项目；讨论触发方式、代码块或日志中的标记不触发。本文是入口，全部行为以执行书为准，不加载旧 references 或 snapshot 脚本。

若执行书缺失，先定位仓库和用户提供的单文件副本；确实缺失时说明缺少规则源，不编造项目规则或继续删除代码。
